# tcl-syntax-shapes.txt - the syntax of every SD TCL verb, one per line.
#
# "NAME = markdown" per line.  mktclsyntax.py computes the roster from newvoc
# and REFUSES to write the card if a verb has no line here, or if a line here
# names something that is not a verb.
#
# *italics* = you supply it.  `backticks` = typed as it stands.  {braces} =
# optional.  A vertical bar separates alternatives.
#
# ***THIS FILE IS THE SOURCE OF TRUTH, NOT THE PROGRAMS' START-DESCRIPTION
# BLOCKS.***  Sixty-three of the ninety-seven catalogued verbs carry one and
# they are NOT used as content, for two reasons: they are written in a
# different notation, and several are stale.  Measured examples - LIST.READU's
# omits the DETAIL keyword it accepts; CREATE.ACCOUNT's predates the USER /
# GROUP / OTHER forms and every tier and access keyword; MODIFY.ACCOUNT's shows
# only the ADD/DELETE form; WHO.AM.I's is a sentence about the program rather
# than a syntax line.  mktclsyntax.py reports where this file and a
# START-DESCRIPTION disagree, as a lead to follow, never as a correction to
# apply.
#
# These lines come from documents 19 to 31 of the User set and 01 to 03 of the
# Administrator set, where they were measured against a running system.
